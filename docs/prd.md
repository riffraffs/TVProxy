# TVProxy

电视 Wi-Fi 没有手动代理。TVProxy 用系统 VPN 接管全部出站流量，转到同一 Wi-Fi 下电脑上的 Clash Verge（或其它 SOCKS5 代理）。分流与规则都在上游软件，本应用只负责连上。

## 用法

1. 电脑 Clash Verge 允许局域网，记下混合端口（常见 7890/7897）
2. 电视填电脑局域网 IP + 端口，类型 SOCKS5
3. 保存启动，按提示允许 VPN

> 电视上的「本机地址」是电视自己，别填进服务器。

## 功能范围

- 遥控器界面：状态、本机 IP、类型 / 地址 / 端口
- 全局代理，上游 SOCKS5（HTTP 兼容混合端口）
- 配置本地保存，可停止 / 重启，后台常驻

## 性能

- 占用内存低

## 非目标

- 代理认证
- 电视侧分流 / 按应用绕过
- 手机版 UI

## 平台

华为智慧屏 V 系列（鸿蒙 2.0），遥控器 DPAD，适配 720p / 1080p / 4K。
