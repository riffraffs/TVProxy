TVProxy 一键 VPN 授权工具 使用说明
====================================

一、为什么需要这个工具
HarmonyOS 电视(如华为智慧屏)系统里缺少 VPN 授权弹窗组件
(com.android.vpndialogs), TVProxy 调用系统 VPN 时拿不到授权,
无法启动全局代理。本工具通过 ADB 直接授予 TVProxy 的
ACTIVATE_VPN 权限, 从而跳过系统弹窗。

二、使用步骤
1. 电视上开启"网络调试":
   设置 - 系统 - 关于 - 连续点击版本号进入开发者选项,
   打开 "USB 调试" 与 "网络调试"。
2. 双击 grant_vpn.bat。
3. 输入电视 IP 地址, 回车(默认端口 5555, 可输入 IP:端口)。
4. 电视屏幕弹出调试授权时, 点击 "允许"。
5. 回到电脑按任意键, 脚本自动授权并显示结果。
6. 打开电视上的 TVProxy, 点击连接即可。

三、常见问题
- 连接失败: 确认电视与电脑在同一局域网, 网络调试已开启。
- 授权后仍弹窗: 电视重启后可能重置权限, 重新运行本脚本即可。
- 端口不是 5555: 输入时写成 192.168.3.51:端口 的形式。

四、关于"安装授权组件"的方案
VPN 授权弹窗组件是系统级(priv-app)组件, 需要 platform 平台签名,
HarmonyOS 电视系统锁定、无法 root, 因此无法安装该组件。
用 ADB 授予 ACTIVATE_VPN 权限是当前唯一可行的方案。

五、目录内容
- grant_vpn.bat   一键授权脚本(双击运行)
- adb.exe         Android 调试桥工具
- AdbWin*.dll / libwinpthread-1.dll   adb 运行依赖
整个目录可整体复制到任意 Windows 电脑使用。
